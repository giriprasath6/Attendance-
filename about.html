ℹ️ About This Project

Smart Attendance System using GPS Verification

🎯 Objective

  • Eliminate manual roll-calling during class
  • Prevent proxy attendance using real GPS
  • Auto-generate attendance reports
  • Provide paperless record management

🛠️ Tech Stack

  • HTML5 + CSS3 + JavaScript
  • HTML5 Geolocation API
  • Google Forms + Google Sheets
  • Google Apps Script (backend logic)
  • GitHub Pages (hosting)

✨ Features

  • QR-based check-in (under 10 seconds)
  • GPS radius verification (Haversine formula)
  • Rotating Class Code (prevents link sharing)
  • Duplicate entry prevention
  • Real-time live dashboard
  • Daily email report to teacher
